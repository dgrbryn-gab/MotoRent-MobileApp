# Image Assets Placeholder

This directory contains image assets for the MotoRent Dumaguete app.

Since we're using placeholder icons for motorcycles instead of actual images, 
you can add your motorcycle images here with the following naming convention:

- honda_pcx_160.jpg
- yamaha_nmax_155.jpg
- honda_beat_150.jpg
- honda_click_160.jpg
- yamaha_aerox_155.jpg
- suzuki_skydrive_125.jpg
- honda_dio_160.jpg
- yamaha_gravis_125.jpg

The app currently uses Material Icons as placeholders but can be easily updated 
to use actual motorcycle images once they are added to this directory.
